# LukePepin.github.io

Personal page. Right now it hosts the **Man of the Year 2027** scheduling form.

- `index.html`: the phone-first form (name and password, then days, times, questions, review)
- `admin.html`: private results (heatmap, best days, answers, blocked days, CSV, delete)
- `assets/api.js`: where the form sends data (the Mac's Tailscale Funnel URL)

The server, the names, the dates and the questions live in `Moty-Results/scheduler/`.
That folder's README covers running it.

The old SentryC2 site is archived at the git tag `sentryc2-archive`.
